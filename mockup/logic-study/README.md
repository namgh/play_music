# Logic Pro 분석 (2026-11-11)

출처: Apple 공식 사용 설명서 **Logic Pro for Mac 13.0** (support.apple.com/guide/logicpro) ·
apple.com/logic-pro 제품 페이지. `guide/` 는 설명서 그림, `product/` 는 제품 페이지 그림 원본.
FigCraft `studio-redesign.figcraft` 의 "Logic Pro 분석" 페이지에 같은 그림이 설명과 함께 있다.

설명서에 적힌 사실과 그림에서 내가 읽은 관찰을 구분해 적는다. 관찰에는 (관찰)이라고 표시한다.

## 1. 뼈대 — 창 하나, 영역을 켜고 끈다

메인 창(⌘1) 하나에 영역들이 붙었다 떨어졌다 한다. 별도 창으로 띄울 수도 있지만 기본은 한 창이다.

| 영역 | 위치 | 여닫기 | 하는 일 |
|---|---|---|---|
| 컨트롤 바 | 맨 위 | 항상 | 영역 버튼 · 재생 · **LCD** · 자주 쓰는 명령 |
| 트랙 영역 | 가운데 | 항상 | 리전을 녹음·배치. 메뉴바/눈금자/트랙 헤더/작업 공간/재생 헤드 |
| 인스펙터 | 왼쪽 열 | I | 리전·트랙 파라미터 + 선택 트랙 채널 스트립 + 출력 스트립 |
| 브라우저 | 왼쪽 | B | 패치·루프·프리셋 검색(자연어 가능), 선택 트랙에 바로 적용 |
| 편집기 | 아래 | E | 피아노 롤 · 악보 · 스텝 · 오디오 트랙(Flex) · Session Player |
| 믹서 | 아래 | X | 채널 스트립. 단일/트랙/전체 보기 |
| 스마트 컨트롤 | 아래 | (버튼) | 악기별 핵심 노브만 추린 단순화 층 |
| 목록 편집기·노트·파일 | 오른쪽 | (버튼) | 이벤트·마커·템포 숫자 편집 등 |

**LCD**: 컨트롤 바 가운데. 재생 위치(마디·박), 템포, 조성, 박자를 보이고 거기서 바로 바꾼다.
모드 — 박&프로젝트 / 박&시간 / 박 / 시간 / 사용자 지정(CPU·디스크까지).

## 2. 편집 — 음 하나를 다루는 방식

- **피아노 롤**: 음표는 시간 격자 위 막대. **세기는 색**(관찰: 초록→노랑→빨강). 왼쪽 자체 인스펙터에
  퀀타이즈·강도·스윙·스케일 퀀타이즈·세기. 위 탭에서 피아노 롤 / 악보 / 스마트 템포 전환.
  (관찰) 제품 사진에서는 음표 안에 `G3 | 33` 처럼 음 이름과 세기가 글자로 박혀 있고,
  오토메이션 곡선이 같은 편집기 아래에 붙어 있다.
- **Flex Pitch**: 녹음된 오디오를 음표 막대로 바꿔 보여 주고, 실제 음정 곡선을 그 위에 그린다.
  음표 하나에 **핫스팟 6개** — 위 왼쪽 *시작 음정 드리프트*, 위 가운데 *비브라토*,
  위 오른쪽 *끝 음정 드리프트*, 아래쪽 *게인* 등(설명서 문장이 중간에서 잘려 나머지 둘은 미확인).
  드래그하면 값 말풍선(`Vibrato 116%`)이 뜬다.
- **Pitch Correction 플러그인**: 건반으로 스케일 지정 + *반응 속도(ms)* + *허용 오차(센트)* 노브.
- **스텝 시퀀서**: 하드웨어 방식. 줄 = 소리 또는 오토메이션, 칸마다 세기·음정·게이트.

## 3. 생성·보조 (Logic 이 "AI" 로 내세우는 것)

Session Player(키보드·베이스·드럼 연주자, 코드 트랙을 따라 연주, 복잡도/세기 + 채우기·스윙),
코드 인식, Stem Splitter(곡을 6갈래로 분리), Mastering Assistant(분석 → 자동 보정 → 몇 개만 사람이 조정),
Smart Tempo. 전부 **결과가 일반 리전·플러그인으로 남아 사람이 이어서 편집**한다.

## 4. 시각 언어 (관찰)

- 바탕은 거의 무채색 짙은 회색, 컨트롤 바만 한 단계 밝은 회색. 장식 없음.
- 색은 **리전에만** 쓴다. 트랙(또는 트랙 묶음)마다 채도 높은 색 — 파랑·청록·초록·보라·분홍·노랑.
  화면의 색은 거의 전부 "내 음악"에서 나온다.
- 리전 안에 내용 미리보기(파형 또는 MIDI 음표 선)가 항상 그려져 있다.
- 선택·활성은 파란색 하나로 통일(스냅 켬, 탭 선택, 툴 버튼).
- 버튼은 둥근 알약 묶음, 아이콘 위주. 글자는 작고 촘촘하다 — 화면 밀도가 높다.
- 플러그인·악기 창만 예외적으로 실물감·사진·빛나는 스펙트럼을 쓴다.
- iPad 판은 같은 구조에서 헤더를 좁히고 리전 면적을 늘렸다.

## 5. 우리 제품에 비추어 본 점

- **우리 음 파라미터가 Flex Pitch 핫스팟과 거의 같다.** 우리 시안의 시작 글라이드 ↔ 시작 드리프트,
  흔들림 ↔ 비브라토, 포먼트 유지 ↔ 포먼트. Logic 은 이걸 **녹음된 오디오**에 하고, 우리는
  **음표(MIDI) 도메인**에서 물리 모델로 한다(확정 결정 2번). 화면 표현 방식(음표 위 손잡이 + 값 말풍선)은
  그대로 빌려 올 수 있다.
- Logic 의 정밀도 표현은 "허용 오차 10센트" 수준이다. 우리 주장(±1센트, 분수 딜레이)은 Logic 화면에
  드러나지 않는 축이라 차별점으로 보여 줄 여지가 있다.
- Session Player 의 "생성 결과가 그냥 편집 가능한 리전으로 남는다" 구조는 우리 Phase 3
  (편집 함수를 AI 가 호출, `AI_GENERATION.md`)과 같은 방향이다.
- 대상은 **전문가가 기본**이다(2026-11-15 사용자 확인). 그래서 Logic 을 단순화하는 게 아니라
  Logic 과 **차별**해야 한다. 생김새를 그대로 가져오지 않는다 — 위 "음 단위 정밀 편집"처럼
  Logic 화면에 없는 축을 전면에 둔다.
