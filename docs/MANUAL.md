## 1. 맨 위 줄

왼쪽부터 순서대로입니다.

| 자리 | 설명 |
|---|---|
| **곡 이름** | 눌러서 바꿉니다. 옆의 "저장됨"은 자동 저장 상태입니다 |
| **보기 단추 5개** | 편집기 · 믹서 · 라이브 루프 · 도우미 · 튜닝 도구 |
| **⏮ 맨 앞으로** | 커서를 곡 처음으로 |
| **▶ 재생 / 정지** | 커서 자리부터 재생합니다 (Space) |
| **● 녹음** | 고른 클립에 연주를 녹음합니다 |
| **녹음 방식 ▾** | 바꿔 녹음 · 겹쳐 녹음 · 펀치 인/아웃 · 방금 연주 담기 ([7장](#7-연주와-녹음)) |
| **메트로놈** | 박을 똑딱 소리로. 곡에 저장되지 않고 내보낸 파일에도 안 섞입니다 |
| **1·2 카운트인** | 녹음·재생 전에 한두 마디를 세어 줍니다 (마디 수는 설정에서) |
| **건반** | 화면 아래 연주 칸을 엽니다 |
| **반복** | 반복 구간을 켜고 끕니다 |
| **검은 창** | 지금 위치(마디.박.틱 또는 타임코드) · 템포 · 조성 · 박자. 숫자를 눌러 바꿉니다. **탭**을 박자에 맞춰 누르면 템포가 잡힙니다 |
| **곡 ▾** | 곡 길이, 스윙, 템포 변화 지우기, 타임코드(프레임 수·시작 시각) |
| **↶ ↷** | 되돌리기 · 다시 실행 |
| **폴더** | 파일 메뉴 — 새 곡·저장·열기·가져오기·화면 색·클라우드 |
| **⚙** | 설정 |
| **?** | 짧은 도움말과 명령 찾기 |
| **사람 모양** | 계정 |
| **내보내기** | 오디오 파일로 받기 ([15장](#15-내보내기)) |

**검은 창의 조성**을 정해 두면 피아노 롤이 그 조의 음을 구분해 보여 주고, 악보의 조표와 "스케일에 맞추기"가 그 조를 씁니다.

## 2. 타임라인 — 트랙과 클립

화면 위쪽입니다. 트랙이 세로로 쌓이고 시간이 가로로 흐릅니다.

### 눈금자

- **누르면** 그 마디로 커서가 갑니다.
- **누른 채 끌면** 스크럽 — 지나가는 음이 들립니다.
- 마디 번호를 누르면 **그 마디부터의 박자·조성**을 바꿀 수 있습니다.

### 트랙 만들기

- **+ 트랙** — 악기 트랙.
- **+ 오디오** — 마이크 녹음이나 오디오 파일을 놓는 트랙.

### 트랙 한 줄에 있는 것

| | |
|---|---|
| 색 띠 | 트랙 색. 끌어서 순서를 바꿉니다 |
| 악기 이름 목록 | 눌러서 악기를 바꿉니다 |
| **M** | 뮤트 — 이 트랙을 끕니다 |
| **S** | 솔로 — 이 트랙만 듣습니다 |
| 슬라이더 | 음량 |
| 작은 막대 | 레벨 미터 — 빨갛게 닿으면 너무 큽니다 |
| **A** | 오토메이션 곡선을 펼칩니다 ([11장](#11-오토메이션)) |

### 트랙 ▾ (또는 이름 칸 우클릭)

| 동작 | 설명 |
|---|---|
| 트랙 복제 | 악기·이펙트·클립째 복제해 바로 아래에 |
| 위로 / 아래로 옮기기 | 순서 바꾸기 |
| 스택 | 여러 트랙을 폴더로 묶습니다. 접기, 스택 전체 뮤트·솔로, 풀기 |
| 보호 | 클립·음·오토메이션을 못 고치게 잠급니다 |
| 숨기기 | 목록에서 감춥니다. 소리는 그대로 납니다 |
| ❄ 프리즈 | 악기·이펙트를 오디오로 구워 CPU를 아낍니다. 얼린 동안은 못 고치고, 다시 누르면 녹습니다 |
| 바운스 인 플레이스 | 이펙트까지 거친 소리를 바로 아래 오디오 트랙에 놓고 원래 트랙은 뮤트합니다 |

### 클립

트랙의 빈 레인을 누르면 클립이 생깁니다. 클립을 누르면 아래 편집기에 그 안의 음이 열립니다.

- **끌기** — 옮기기 (다른 트랙으로도).
- **끝을 끌기** — 길이 바꾸기.
- 클립 위의 작은 단추 — 바로 뒤에 복제, 지우기.

### 클립 ▾ (또는 클립 우클릭)

| 동작 | 설명 |
|---|---|
| 나누기 (커서에서) | 커서 자리에서 둘로 |
| 다음 클립과 합치기 | 같은 트랙의 다음 클립과 하나로 |
| 끝까지 반복 | 곡 끝(또는 다음 클립)까지 되풀이 |
| 에일리어스 만들기 | 원본을 따라가는 복사본. 원본을 고치면 같이 바뀝니다. "진짜 복사로 바꾸기"로 떼어 냅니다 |
| 클립 뮤트 | 지우지 않고 소리만 뺍니다 |
| 색 | 여섯 가지 중 고르기 |

## 3. 글로벌 트랙 — 구간·마커·코드·템포·박자

타임라인 맨 위의 줄들입니다. **G** 또는 "글로벌" 단추로 켜고 끕니다.

### 구간 (인트로·벌스·코러스)

- 빈 곳을 눌러 구간을 만듭니다. 이름과 길이를 왼쪽 칸에서 고칩니다.
- 구간을 고르면 왼쪽 칸에 **앞/뒤 구간과 자리 바꾸기**, **복제**(안의 음악째 바로 뒤에), **지우고 당기기**(안의 음악째), **표시만 지우기**가 나옵니다.
- 구간은 내보내기 범위("코러스만")와 라이브 루프의 장면 만들기에도 쓰입니다.

### 마커

- 빈 곳을 눌러 마커를 놓고, 누르면 그 자리로 갑니다.
- **⌥,** / **⌥.** 로 이전·다음 마커로 건너뜁니다.

### 코드

- 마디에 코드 기호를 넣습니다. 악보에서 마디 위에 표시되고, 도우미의 베이스·건반 연주자가 이 코드를 따라갑니다.
- **음에서 찾기** — 드럼을 뺀 트랙의 음에서 코드 진행을 알아냅니다 (기존 코드는 바뀝니다).
- **♭ / ♯** — 코드 기호 전체를 반음 내리고 올립니다.

### 템포

- 줄의 빈 곳을 누르면 템포 변화 지점이 생깁니다.
- 점을 **위아래로 끌면** 템포, **옆으로 끌면** 위치가 바뀝니다.
- **Shift+누르기** — 그 지점까지 서서히 변하게(램프).
- **두 번 누르기** — 지점 지우기.

### 박자·조성 변화

- 눈금자의 마디 번호를 누르면 왼쪽 칸에서 그 마디부터의 박자(3/4, 6/8, 7/8…)와 조성을 정합니다.

## 4. 편집기 — 피아노 롤

화면 아래쪽입니다. 오른쪽 위에서 **피아노 롤 · 스텝 · 이벤트 목록 · 악보**를 고릅니다.

### 음 다루기

| 동작 | 방법 |
|---|---|
| 음 넣기 | 빈 곳 클릭 |
| 여러 음 고르기 | 빈 곳에서 끌기 (범위 선택), Shift+클릭으로 더하기 |
| 옮기기 | 음을 끌기. ↑↓ 반음씩, ←→ 격자 한 칸씩 |
| 길이 바꾸기 | 음의 오른쪽 끝을 끌기 |
| 지우기 | Delete |
| 선택 해제 | Esc |

### 도구 줄

| | |
|---|---|
| **편집 ▾** | 복사(⌘C) · 붙여넣기(⌘V, 커서 자리에) · 바로 뒤에 복제(⌘D) · 전체 선택(⌘A) · 삭제 |
| **기능 ▾** | 아래 표 |
| **격자** | 음이 달라붙는 간격 (1/4 ~ 1/32, 셋잇단) |
| **음 길이** | 새로 찍는 음의 길이 |
| **세기** | 새로 찍는 음의 세기 |
| **색** | 음을 무엇으로 칠할지 — 손댄 음 · 세기 · 음이름 |
| **가로 / 세로** | 확대·축소 |
| **줄 접기** | 쓰는 음높이만 보이게 접습니다 |
| **표시 음역** | 옥타브 막대를 끌어 보이는 범위를 잡습니다. "음에 맞추기"가 정확히 맞춰 줍니다 |
| **겹쳐 보기** | 다른 트랙의 음을 흐리게 깔아 봅니다 (베이스를 보며 멜로디 찍기) |

### 기능 ▾

| 동작 | 설명 |
|---|---|
| 퀀타이즈 | 고른 음을 격자에 맞춥니다 |
| 고른 구간을 반복 구간으로 (⌘L) | 고른 음의 범위를 반복 재생 |
| 레가토 | 다음 음까지 길이를 늘립니다 |
| 겹침 없애기 | 같은 음높이가 겹치는 곳을 잘라 냅니다 |
| 세기 +10% / −10% | |
| 사람처럼 | 타이밍과 세기를 조금 흔들어 기계적인 느낌을 줄입니다 |

### 아래 레인

- **세기(벨로시티) 레인** — 음마다 막대 하나. 끌어서 여러 음의 세기를 한 번에 칠합니다.
- **음정 곡선 레인** — 음 하나의 음정이 시간에 따라 변하게 합니다. 글라이드(미끄러져 올라가기)·비브라토를 슬라이더로 주거나, 직접 점을 찍어 곡선을 그립니다. 점을 다시 누르면 지워집니다.

## 5. 편집기 — 스텝·이벤트 목록·악보

### 스텝 시퀀서

드럼과 반복 패턴에 씁니다. 칸 하나가 음 하나입니다.

- **드럼 트랙**을 고르면 줄이 드럼 종류(킥·스네어·하이햇이 한 판에), **선율 트랙**이면 줄이 음높이입니다.
- **누르기** — 켜기/끄기.
- **Alt+누르기** — 강세.
- **Shift+누르기** — 래칫(한 칸을 2·3·4번으로 쪼개 치기).
- 위에서 칸 크기(1/16 등)와 게이트(음 길이 비율)를 정합니다.

### 이벤트 목록

모든 음을 숫자 표로 봅니다. 위치(마디·박·틱), 길이, 음높이(MIDI 번호), 세기를 직접 고칩니다.

위의 **변환 줄**은 고른 음(없으면 전부)에 한 번에 적용합니다.

| 변환 | 설명 |
|---|---|
| +옥타브 / −옥타브 | 한 옥타브 올리고 내리기 |
| 세기 100 으로 | 세기를 모두 같게 |
| 크레셴도 / 디크레셴도 | 세기가 점점 커지거나 작아지게 |
| 거꾸로 | 음의 순서를 뒤집습니다 |
| 음높이 뒤집기 | 정한 음(기본 60 = C4)을 축으로 위아래를 뒤집습니다 |

### 악보

오선지로 봅니다. 한 줄에 네 마디, 코드 줄의 코드가 마디 위에 나옵니다.

- 음이 넓게 퍼진 피아노 트랙은 **큰보표**(높은음자리 + 낮은음자리)로 그려집니다.
- 세기에 따라 **셈여림 기호**(pp ~ ff)가 붙습니다.
- 음을 고르고 **가사** 칸에 글자를 넣고 Enter. 가사는 음 아래에 표시됩니다.
- **성부 바꾸기** — 고른 음을 둘째 성부(기둥이 아래로)로 보냅니다.
- **기호 지우기** — 고른 음에 붙인 기호를 뗍니다.
- **MusicXML 내보내기** — 드럼을 뺀 모든 트랙. MuseScore·Sibelius·Logic에서 엽니다.
- **인쇄** — 브라우저 인쇄 창으로 (PDF로 저장 가능).

## 6. 오른쪽 칸 — 음 편집·컨트롤·브라우저

**I**로 켜고 끕니다. 탭 세 개입니다.

### 음 편집

고른 음 하나의 값을 정밀하게 고칩니다.

- **반음 단추** — 음높이를 반음씩.
- **센트 슬라이더** — 반음의 100분의 1 단위로 음정을 올리고 내립니다.
- **주파수 입력** — Hz로 직접. 음높이와 센트로 자동 환산됩니다.
- 시작·길이·세기.

### 컨트롤 (스마트 컨트롤)

고른 트랙의 손잡이 8개입니다.

- 처음에는 볼륨·팬·악기의 주요 값·이펙트가 자동으로 물려 있습니다.
- **끌어서 돌리고, 두 번 누르면 처음 값**으로 돌아갑니다.
- 손잡이 아래 **이름을 누르면** 무엇을 조절할지 바꿉니다 (매핑). 범위(최소·최대)와 곡선, 거꾸로를 정하고, **＋ 대상**으로 손잡이 하나가 여러 값을 함께 움직이게 할 수 있습니다.

같은 탭 아래에 **MIDI 이펙트**가 있습니다. 음 자체는 그대로 두고 소리 나는 방식만 바꿉니다.

| MIDI 이펙트 | 설명 |
|---|---|
| 아르페지에이터 | 화음을 한 음씩 쪼개 연주합니다. 방향(위로·아래로·위아래·무작위·친 순서)과 빠르기 |
| 코드 트리거 | 한 음을 치면 화음이 납니다. 코드 모양을 고릅니다 |
| 노트 리피터 | 음을 정한 간격으로 되풀이합니다 |
| 스케일 맞추기 | 곡의 조성에 없는 음을 가까운 음으로 옮깁니다 |
| 세기 처리 | 세기를 고정·더하기·배율·무작위로 바꿉니다 |
| 옮김(트랜스포즈) | 반음 단위로 올리고 내립니다 |

### 브라우저

악기를 찾고, **미리 듣고**, 고른 트랙에 넣거나 새 트랙으로 만듭니다. 손잡이를 만진 음색을 **내 음색(패치)**으로 저장해 다른 곡에서 다시 씁니다.

## 7. 연주와 녹음

### 연주 칸

위쪽 **건반** 단추로 엽니다.

- **화면 건반** — 마우스로 칩니다.
- **컴퓨터 자판** — 자판이 건반이 됩니다. 옥타브 올리기·내리기, 연주 세기를 정합니다.
- **코드 스트립** — 단추 하나가 화음 하나. 곡의 조성에 맞는 코드가 깔리고, **7th**를 켜면 7화음이 됩니다.
- **드럼 패드** — 드럼 트랙용.
- **스텝 입력** — 켜면 친 음이 커서 자리에 찍히고 커서가 음 길이만큼 나갑니다. **Shift를 누른 채 치면** 커서가 안 나가서 화음이 됩니다.

### MIDI 건반

연결하면 설정(⌘,)의 MIDI 장치에 뜨고, 고른 트랙의 악기로 바로 소리가 납니다.

### 녹음 방식

| 방식 | 설명 |
|---|---|
| 바꿔 녹음 | 새로 친 것이 들어가고, 옛 음은 **테이크**로 보관됩니다. 편집기 위의 "테이크 N개 · 바꿔 듣기"에서 골라 바꿔 넣습니다 |
| 겹쳐 녹음 | 있던 음에 더합니다 |
| 펀치 인/아웃 | 반복 구간 안에서 친 것만 녹음합니다. 앞뒤는 준비 연주입니다 |
| 방금 연주 담기 | 녹음을 안 눌렀어도, 재생하며 친 것을 고른 클립에 담습니다 |

## 8. 오디오 트랙

- **마이크 녹음** — 오디오 트랙을 고르고 녹음 단추. 처음에 마이크 권한을 묻습니다.
- **파일 가져오기** — 폴더 → 오디오 가져오기. WAV·MP3·AAC·FLAC·OGG.
- **영상 소리** — 영상 창의 "소리 꺼내기".

오디오 클립을 누르면 아래에 **오디오 편집기**가 열립니다. 파형 위에서:

| | |
|---|---|
| 시작 다듬기 · 길이 | 파일의 어느 부분을 쓸지 |
| 게인 | 클립 음량(dB) |
| 페이드 인 / 아웃 | 처음과 끝을 부드럽게 |
| 거꾸로 | 뒤집어 재생 |
| 노멀라이즈 | 가장 큰 소리를 기준에 맞춥니다 |
| 처음대로 | 고친 것을 모두 되돌립니다 |

클립 나누기·옮기기·복제는 악기 클립과 같습니다. 녹음한 소리의 박자·음정을 늘이고 고치는 기능(Flex)은 아직 없습니다.

## 9. 믹서

위쪽 두 번째 보기입니다. 채널이 왼쪽부터 **트랙 → 버스 → VCA → 마스터** 순으로 섭니다.

### 채널 하나 (위에서 아래로 = 소리가 흐르는 순서)

| | |
|---|---|
| **인서트** | 이펙트 칸. "+ 인서트"로 더하고, 이름을 누르면 아래에 그 이펙트의 손잡이가 열립니다. 켜짐/끔, 제거, 순서 |
| **센드** | 이 트랙의 소리 일부를 버스로 보냅니다. 양을 0으로 하면 끊깁니다. **프리** — 페이더와 상관없이 보냅니다 |
| **출력** | 마스터로 갈지, 버스로 갈지 |
| **그룹 / VCA** | 아래 설명 |
| **팬** | 좌우 위치. 두 번 누르면 가운데 |
| **페이더 + 미터** | 음량. 두 번 누르면 기본값 |
| **M / S** | 뮤트 · 솔로 |

### 버스 · VCA · 그룹

- **버스(Aux)** — 여러 트랙이 함께 쓰는 이펙트 통로. 리버브를 버스 하나에 걸고 여러 트랙에서 센드로 보내면 한 공간에 있는 것처럼 들립니다.
- **VCA** — 여러 트랙의 음량을 페이더 하나로 움직입니다. 소리가 지나가는 길은 아닙니다.
- **그룹** — 묶인 트랙의 볼륨·뮤트·솔로가 함께 움직입니다.

### 지연 보정 (PDC)

일부 이펙트는 처리하느라 소리가 조금 늦어집니다. 켜 두면 나머지 트랙을 그만큼 늦춰 박이 어긋나지 않게 맞춥니다. 믹서 위에 지금 보정 중인 시간이 표시됩니다.

### 마스터

모든 소리가 모이는 마지막 채널입니다. 여기에 리미터를 걸고 천장을 −1dB에 두면 스트리밍에 올리기 안전합니다.

## 11. 오토메이션

시간에 따라 값이 변하게 합니다 (후렴에서 음량 올리기, 필터가 서서히 열리기).

1. 트랙의 **A**를 눌러 곡선 줄을 펼칩니다.
2. 무엇을 움직일지 고릅니다 — 볼륨, 팬, 그 트랙에 걸린 이펙트의 값.
3. **빈 곳을 누르면 점**, **점을 끌면 이동**, **점을 두 번 누르면 삭제**.

재생과 내보내기에 똑같이 반영됩니다. 3D 패너의 방향·높이도 곡선으로 움직일 수 있습니다.

## 12. 라이브 루프

위쪽 세 번째 보기입니다. 트랙 × 장면의 격자에서 칸을 눌러 가며 즉석으로 편곡을 짭니다.

- **칸을 누르면** 그 트랙이 그 칸의 연주로 바뀝니다 (트랙마다 하나씩 울립니다).
- **장면 머리의 ▶** — 그 줄 전체를 한꺼번에.
- **구간에서 장면 만들기** — 편곡 구간(인트로·벌스…)마다 장면 하나를 만듭니다.
- **반복 구간을 장면으로** — 반복 구간(⌘L)의 음을 새 장면으로.
- **편곡으로 보내기** — 연주한 장면 순서대로 곡 끝에 붙입니다.
- **모두 멈춤**.

## 13. 도우미

위쪽 네 번째 보기입니다. 규칙으로 동작해서 인터넷 없이 됩니다.

### 세션 연주자

코드 줄과 구간을 읽고 반주를 만들어 줍니다.

| 연주자 | 고를 것 |
|---|---|
| **드럼** | 스타일, 복잡도, 세기, 구간 끝 필인. 킥·스네어·하이햇 트랙에 나눠 칩니다 |
| **베이시스트** | 스타일, 리듬(4분음표·8분음표·당김음). 코드 근음을 따라갑니다 |
| **건반 연주자** | 스타일, 연주 범위. 가까운 자리바꿈으로 코드를 잇습니다 |

만들어진 것은 보통 음이라 그대로 고칠 수 있습니다.

### 마스터링 도우미

곡을 한 번 그려서 재고(통합 라우드니스, 트루 피크, 저역·고역 균형), 마스터에 걸 EQ·컴프레서·리미터 값을 제안합니다. 라우드니스 목표를 고르고 적용한 뒤 다시 내보내면 됩니다.

### 대화형 도우미

"코러스 베이스를 더 펑키하게" 같은 말로 곡을 고치는 자리입니다. **아직 준비 중**이고 지금은 동작하지 않습니다.

### 튜닝 도구 (다섯 번째 보기)

악기 소리를 만드는 사람을 위한 화면입니다. 악기의 값을 바꾸며 실시간으로 듣고, 스펙트럼·스펙트로그램으로 보고, 스냅샷을 저장해 A/B로 비교합니다. 곡을 만드는 데는 필요 없습니다.

## 14. 영상

폴더 → **영상 가져오기**. 왼쪽 아래에 영상 창이 뜨고 재생 위치를 따라갑니다.

| | |
|---|---|
| 타임코드 | 영상의 지금 시각. 프레임 수는 **곡 ▾**에서 (23.976 ~ 60fps), 시작 타임코드도 거기서 |
| 곡과 어긋남 | 영상이 곡의 몇 초에서 시작하는지. 음수면 영상이 먼저 시작 |
| 장면 마커 | 지금 자리에 "장면 1, 2…" 마커 |
| 박에 맞추기 | 지금 자리가 박에 떨어지게 템포를 조금 바꿉니다. 8% 넘게 바꿔야 하면 하지 않고, 템포 변화가 있는 곡에서는 동작하지 않습니다 |
| MP4 / WebM | 내보낼 형식 |
| 영상과 내보내기 | 영상의 그림 + 곡의 믹스를 한 파일로. 영상의 원래 소리는 빠집니다 |
| 소리 꺼내기 | 영상의 소리를 오디오 트랙으로 올립니다 |
| ⤡ / ✕ | 창 크기 · 영상 빼기 |

## 15. 내보내기

### 오디오 (노란 내보내기 단추)

| 항목 | 선택지 |
|---|---|
| 범위 | 곡 전체 · 반복 구간 · 구간 하나 |
| 형식 | WAV · FLAC · MP3 · M4A(AAC) · OGG(Opus) |
| 비트 깊이 (무손실) | 24bit · 16bit + 디더 · 32bit float(WAV만) |
| 비트레이트 (손실) | 128k · 192k · 256k · 320k |
| 표본율 | 48kHz · 44.1kHz (OGG는 48kHz만) |
| 끝 뒤 2초 꼬리 | 리버브·딜레이가 끝까지 울리게 |
| 노멀라이즈 | 가장 큰 소리를 −1dBFS에 |
| 트랙별 스템 | 트랙마다 파일 하나씩, ZIP으로 |

내보낸 뒤 **통합 라우드니스(LUFS) · 트루 피크 · 샘플 피크 · 길이**가 표시됩니다. 트루 피크가 −1dBTP를 넘으면 경고가 뜹니다.

뮤트·솔로는 내보낸 파일에 그대로 반영됩니다. 메트로놈은 안 섞입니다.

### 그 밖의 형식

| 형식 | 어디서 | 담기는 것 |
|---|---|---|
| MIDI (.mid) | 폴더 → MIDI 내보내기 | 음·템포·박자·트랙 이름·가사. 센트 음정은 반올림(알려 줍니다) |
| MusicXML | 악보 보기 | 드럼을 뺀 트랙의 악보·코드·가사 |
| 곡 파일 (.json / .zip) | 폴더 → 파일로 저장 (⌘S) | 곡 전체. 오디오가 있으면 소리까지 묶은 ZIP |
| MP4 / WebM | 영상 창 | 영상 + 곡의 믹스 |

## 16. 곡 관리 — 저장·버전·파일·클라우드

### 곡 고르기 창 (⌘O)

- **새 곡** — 템플릿: 빈 곡 · 밴드 · 일렉트로닉 · 어쿠스틱 · 피아노 솔로.
- **예제 곡** — "첫눈 오는 밤"(겨울 댄스, 124BPM 4/4), "작은 종소리"(캐롤 왈츠, 108BPM 3/4).
- **최근 곡** — 열었던 곡이 남습니다.
- **버전** — 지금 곡에 이름을 붙여 남깁니다("브리지 바꾸기 전"). 마음껏 고친 뒤 그 버전으로 돌아갈 수 있습니다.

### 저장 방식 네 가지

| | 어디에 | 언제 쓰나 |
|---|---|---|
| 자동 저장 | 이 기기 | 고칠 때마다. 다시 열면 그대로 |
| 최근 곡 · 버전 | 이 기기 | 여러 곡을 오갈 때. 저장 공간이 차면 오래된 곡부터 지워집니다 |
| 파일로 저장 (⌘S) | 내 디스크의 파일 | **중요한 곡은 반드시 이것으로** |
| 클라우드 | 서버 | 로그인했을 때. 다른 기기에서 엽니다 |

### 가져오기

- **파일 열기** — 곡 파일(.json·.zip).
- **MIDI 가져오기** — 다른 프로그램에서 만든 .mid. 악기 번호를 읽어 가장 가까운 악기로, 드럼은 종류별 트랙으로 나눕니다.
- **오디오 가져오기**, **영상 가져오기**.

### 클라우드

폴더 메뉴 아래쪽. 서버에 저장하고 엽니다. 같은 곡을 다른 기기(탭)에서 고쳐 서로 어긋나면, 덮어쓸지 서버 것을 받을지 묻습니다.

### 오류가 났을 때

화면에 문제가 생기면 흰 화면이 되는 대신 안내가 뜨고, 자동 저장본을 파일로 내려받을 수 있습니다.

## 17. 설정

**⌘,** 또는 ⚙.

| 탭 | 내용 |
|---|---|
| **일반** | A4 기준음(조율 — 곡마다 저장), 카운트인 마디 수, 건반 이름 보기 |
| **오디오** | 출력 장치(스피커), 입력 장치(마이크), 지연, 스피커 배치(스테레오·5.1·7.1·7.1.4 — 지금은 표시만) |
| **단축키** | 모든 명령의 키를 바꿉니다. "전부 기본값"으로 되돌리기 |
| **MIDI 장치** | 연결된 입력 장치를 고릅니다 |

**화면 색**은 폴더 메뉴에 있습니다. 준비된 테마를 고르거나 색 편집기에서 색을 하나씩 바꿉니다.

**스크린셋** — 지금의 화면 배치(어떤 칸이 열렸는지, 확대 정도)를 **⇧+숫자**로 저장하고 **숫자**로 부릅니다. 작곡용·믹스용 배치를 따로 두면 편합니다.

## 18. 계정

로그인하지 않아도 곡 만들기·파일 저장·내보내기는 모두 됩니다. 로그인은 클라우드 저장을 위한 것입니다.

- **로그인** — 구글 계정으로만. 처음 누르면 계정이 바로 만들어집니다. 설치한 앱에서는 기본 브라우저가 열리고, 로그인을 마치면 앱으로 돌아옵니다.
- **계정 창** — 표시 이름 바꾸기, 플랜·사용량, 로그아웃, 모든 기기에서 로그아웃, 탈퇴(30일 안에 복구 가능).
